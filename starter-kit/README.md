# Website Trung tâm Tiếng Anh (TTA)
## Giới thiệu dự án
Dự án **Website Quản lý Trung tâm Tiếng Anh (TTA)** là hệ thống số hóa hỗ trợ vận hành, đăng ký khóa học và tra cứu học phí tự động. Hệ thống này được xây dựng với mục tiêu *tối ưu hóa quy trình quản lý* và **nâng cao trải nghiệm học viên**.

## Cấu trúc thư mục dự án
| Thư mục / File | Nội dung mô tả |
| :--- | :--- |
| `data/` | Chứa các file Excel cơ sở dữ liệu |
| `docs/` | Chứa tài liệu kỹ thuật và hướng dẫn sử dụng hệ thống |
| `README.md` | Tài liệu giới thiệu tổng quan về dự án website TTA |

## Quy trình đăng ký học tại TTA
1. Học viên tra cứu danh mục khóa học và học phí trên hệ thống website TTA.
2. Học viên điền thông tin đăng ký và lựa chọn số tháng học mong muốn.
3. Hệ thống tự động tính toán tổng học phí và gửi xác nhận đăng ký thành công.
